1. Компромисс смещения и дисперсии

Усложнение модели обычно уменьшает смещение, но повышает чувствительность к конкретной обучающей выборке.

5
Синий — Bias² · красный — Variance ≥ 0 · зелёный — общая ошибка

Интерпретация

Ошибка ≈ Bias² + Variance + Noise

Все три слагаемых неотрицательны. На графике красная кривая Variance не пересекает линию нулевого уровня.

Bias — смещение; Variance — дисперсия прогноза между обучающими выборками; Noise — неустранимый шум.

2. Полиномиальная регрессия

Изменяйте степень полинома. Схема иллюстрирует, как меняется гибкость модели, а не показывает оценку на реальном наборе данных.

3
Синяя линия — модель · точки — наблюдения

Что происходит?

Слишком простая модель не улавливает структуру данных (недообучение). Слишком гибкая может подстроиться под случайные колебания обучающей выборки (переобучение).

3. Автокорреляция остатков

Выберите тип последовательности. По горизонтали — время или порядок наблюдений, по вертикали — остаток.

DW = Σ(eᵢ − eᵢ₋₁)² / Σeᵢ²

Пересчитано для выбранных остатков:

DW — статистика Дарбина–Уотсона. Около 2 соответствует отсутствию выраженной автокорреляции; меньше 2 — положительной, больше 2 — отрицательной.

Тест Бройша–Пагана

LM = n · R²

Синтетические данные:

LM — статистика теста; p-value — приближённая вероятность при постоянной дисперсии. При малом p-value есть основания подозревать неодинаковый разброс.

5. Кросс-валидация K-fold

Нажмите на блок: он станет тестовым, остальные используются для обучения. Каждый блок по очереди выполняет роль тестового.

5
CV-ошибка — среднее ошибок на тестовых блоках. Она помогает сравнить модели по способности обобщать.

6. Проверьте понимание

Ключевые выводы
  • Качество на обучающих данных не гарантирует качество на новых.
  • Остатки анализируют на структуру, зависимость и постоянство дисперсии.
  • Графики дополняют, но не заменяют формальные тесты.
  • Кросс-валидация помогает сравнивать модели.
Графики построены на синтетических данных. Статистики DW и Бройша–Пагана пересчитываются при переключении режима и служат учебной иллюстрацией.
