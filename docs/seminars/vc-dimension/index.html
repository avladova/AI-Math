Постановка задачи

Бинарная классификация: обучающая выборка $S = \{(x_1,y_1),\ldots,(x_m,y_m)\}$ состоит из $m$ объектов, $x_i$ — признаки объекта, $y_i\in\{-1,+1\}$ — его метка. Из класса функций выбирается $f$. Ошибка $\hat R_m(f)$ — средняя на выборке, $R(f)$ — средняя на новом случайном объекте.

Теория Вапника — Червоненкиса (VC-теория) изучает, насколько класс функций способен подстраиваться под разные бинарные разметки: чем он ёмче, тем выше риск, что малая ошибка на обучении — результат запоминания.

$$R(f) \leq \hat R_m(f)+\sqrt{\frac{h\ln(2em/h)+\ln(4/\delta)}{2m}}$$

Здесь $h$ — VC-размерность класса, $m$ — размер выборки, $\delta$ — допустимая вероятность нарушения гарантии: оценка верна с вероятностью не менее $1-\delta$ сразу для всех $f$ класса. Корень — зазор между обучающей и истинной ошибками; он растёт с $h$ и убывает с $m$.

Что означает «разбить» набор точек

Разметка набора из $n$ точек — способ приписать каждой точке метку $+1$ или $-1$; всего их $2^n$. Класс функций разбивает набор, если для каждой из $2^n$ разметок в нём есть функция, реализующая именно её. VC-размерность $h$ — наибольшее число точек, которые класс способен разбить; расположение точек можно выбирать.

VC-размерность говорит, может ли класс реализовать любую разметку некоторого набора.

Аффинный линейный классификатор

Он разделяет объекты гиперплоскостью (при двух признаках — прямой): $w$ — веса признаков, $b$ — сдвиг, граница — $w^\top x+b=0$.

$$f(x)=\mathrm{sign}(w^\top x+b)$$

Скоринг по двум признакам

$x_1$ — доход (тыс. руб. в месяц), $x_2$ — число просрочек за два года. Нажмите на график, чтобы выбрать заявителя.

Синяя область — решение $+1$ (одобрить), красная — $-1$ (отклонить). Чёрная линия — граница.

Параметры классификатора

Меняйте веса и сдвиг: прямая сдвигается и поворачивается, а решение для выбранного заявителя пересчитывается.

Число признаков и VC-размерность

$$h=d+1$$

$d$ — число признаков.

  • $d=1$: граница — порог, то есть значение признака, при котором решение меняется (например, «одобрить, если доход выше 50»). Допустимы оба направления, поэтому $h=2$; при фиксированном направлении, как в задаче 6.1, $h=1$.
  • $d=2$: прямые на плоскости, $h=3$.
  • $d=10$: гиперплоскости в $\mathbb{R}^{10}$, $h=11$.
