VC-размерность как мера ёмкости класса

Тема 4 • Интерактивный материал по семинару VC-размерности

Теория

Постановка задачи

Пусть $S = \{(x_1,y_1),\ldots,(x_m,y_m)\}$ — обучающая выборка из $m$ объектов. $\hat R_m(\hat f)$ — средняя ошибка обученной функции на этой выборке, а $R(\hat f)$ — средняя ошибка на новом случайном объекте.

VC-теория изучает, насколько класс функций способен подстраиваться под разные бинарные разметки. Чем больше ёмкость класса, тем больше риск, что малая ошибка на обучении окажется результатом запоминания.

$$R(\hat f) \leq \hat R_m(\hat f)+\sqrt{\frac{h\ln(2em/h)+\ln(4/\delta)}{2m}}$$

Здесь $h$ — VC-размерность класса, $m$ — размер обучающей выборки, $\delta$ — допустимая вероятность нарушения гарантии. Корень — теоретический зазор между обучающей и истинной ошибками.

Что означает «разбить» набор точек

Класс функций разбивает набор из $n$ точек, если для каждой из $2^n$ бинарных разметок существует функция класса, которая реализует именно эту разметку.

Прямые на плоскости

Для аффинного линейного классификатора $f(x)=\mathrm{sign}(w^\top x+b)$ в $\mathbb{R}^2$:

$$h=3$$

Три точки общего положения можно разбить всеми $2^3=8$ способами. Для любой конфигурации из четырёх точек найдётся нереализуемая разметка.

Общее правило

$$h=d+1$$

$d$ — число признаков. Поэтому порог на прямой имеет $h=2$, прямые на плоскости — $h=3$, а гиперплоскости в $\mathbb{R}^{10}$ — $h=11$.

Две причины невозможности для четырёх точек

  • Для выпуклого четырёхугольника чередующаяся разметка $+,-,+,-$ не разделяется одной прямой.
  • Если одна точка лежит внутри треугольника из трёх других, её нельзя отделить от всех внешних точек прямой: она находится в их выпуклой оболочке.
Главное различие: VC-размерность спрашивает, может ли класс реализовать любую разметку некоторого набора. Это не то же самое, что вопрос о том, разделяет ли модель одну конкретную обучающую выборку.
