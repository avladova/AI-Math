# AI-Math

Репозиторий материалов по математическим основам машинного обучения, теории обобщения и диагностике регрессионных моделей.

Материалы объединяют теоретические объяснения, семинарские задания, схемы и интерактивные демонстрации. Текст лекции или семинара служит содержательной основой, а интерактивная страница помогает исследовать отдельные зависимости и проверять интуицию.

## Организация материалов

Теоретические материалы находятся в каталоге `семинары/` и доступны как GitHub-совместимые Markdown-файлы. Иллюстрации хранятся в `семинары/assets/` и подключаются из текстов относительными ссылками.

Интерактивные страницы размещаются отдельно в `docs/seminars/`. Файл `docs/index.html` — главная страница курса и каталог интерактивных материалов. Каждая тема имеет собственный каталог с `index.html`. Это разделение позволяет добавлять интерактивные материалы, не дублируя тексты семинаров.

## Публикация

Чтобы опубликовать интерактивные страницы, включите GitHub Pages в настройках репозитория: источник — ветка `main`, каталог `/docs`. Главная страница сайта будет открывать каталог интерактивных материалов.
