## Интерактивные страницы

Интерактивные материалы публикуются в каталоге [`docs/`](docs/) и предназначены для запуска через GitHub Pages. Первая доступная страница посвящена радиусу Рэдемахера:

[Открыть интерактивный семинар по радиусу Рэдемахера](docs/seminars/rademacher/)

Если GitHub Pages ещё не включён, в настройках репозитория нужно выбрать публикацию из ветки `main` и каталога `/docs`.

## Структура репозитория

```text
AI-Math/
├── README.md                 ← описание репозитория
├── семинары/                 ← открытые тексты семинаров
│   ├── README.md             ← каталог и навигация по семинарам
│   ├── *.md                  ← основные материалы
│   ├── assets/               ← рисунки и схемы
│   └── _auxiliary/           ← служебные ключи ответов
├── docs/                     ← интерактивные страницы GitHub Pages
│   ├── index.html             ← каталог интерактивных материалов
│   └── seminars/              ← страницы отдельных семинаров
└── код/                      ← дополнительные материалы и вычислительные примеры
```

## Формат материалов

Основные семинары написаны на русском языке в GitHub-совместимом Markdown. Формулы оформлены в LaTeX, рисунки хранятся отдельно в `assets/` и подключаются относительными ссылками.

Задания находятся в открытом тексте семинара. Ключи ответов хранятся отдельно в каталоге `семинары/_auxiliary/`, чтобы не смешивать студенский материал и служебные материалы преподавателя.

## Лицензия и использование

Материалы предназначены для учебного использования. При переработке отдельных семинаров сохраняйте ссылки на исходный материал и проверяйте, что формулы и изображения корректно отображаются на GitHub.
