Основные файлы предназначены для чтения студентами непосредственно на GitHub. Формулы записаны в Markdown-совместимом LaTeX, а рисунки подключены из каталога `assets/`.

## Как пользоваться материалами

Сначала прочитайте основной Markdown-файл семинара. Затем выполните задания из соответствующего раздела. Интерактивные страницы используются как дополнение: они позволяют менять параметры и наблюдать, как меняются графики и показатели ошибки.

## Структура каталога

```text
семинары/
├── README.md                  ← этот файл
├── *.md                       ← открытые тексты семинаров
├── assets/                    ← рисунки и схемы
└── _auxiliary/                ← служебные ключи ответов
```

Папка `_auxiliary/` содержит ключи ответов для преподавателя и не является частью обязательного студенческого материала. Рисунки из `assets/` являются частью открытых семинаров: их не следует удалять или переименовывать без обновления ссылок в Markdown-файлах.

## Интерактивные страницы

Общий каталог интерактивных материалов доступен по адресу [AI-Math — интерактивные семинары](../docs/). Если GitHub Pages ещё не включён, интерактивные страницы можно открыть после включения публикации из ветки `main` и каталога `/docs` в настройках репозитория.
