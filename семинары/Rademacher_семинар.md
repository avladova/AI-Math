# Радиус Рэдемахера как мера сложности класса функций

> Материал по семинару 2 темы 4 «Математическая теория обобщения и диагностики моделей». Используется как входной материал для следующего семинара по математической диагностике и анализу кривых обучения.

---

## 1. Какую проблему решаем

**Проблема — обобщение.** Модель, обученная на выборке $S = (x_1, \ldots, x_m)$, имеет эмпирическую ошибку $\hat{R}_m$, но нас интересует истинная ошибка $R$ на новых данных. Эти величины могут сильно различаться: модель может запомнить обучающую выборку (переобучение) и плохо работать на новых данных.

**Проблема VC-оценки.** Неравенство Вапника–Червоненкиса
$$R \leq \hat{R}_m + O\!\left(\sqrt{\frac{h\ln(m/h)}{m}}\right)$$
содержит VC-размерность $h$, которая **зависит только от класса функций** и не использует информацию о конкретных данных. Для линейного классификатора в $\mathbb{R}^{10}$ всегда $h = 11$ — независимо от того, какие признаки и сколько данных.

**Что делает Рэдемахер.** Даёт оценку сложности, **зависящую от конкретной выборки** $S$. Если признаки хорошо нормированы и данные «удобные» — оценка будет меньше, чем VC. Если данные «плохие» — оценка близка к VC.

---

## 2. Интуиция

Подбросим монетку для каждого из $m$ объектов и получим случайную разметку $\sigma = (\sigma_1, \ldots, \sigma_m)$, где $\sigma_i \in \{-1, +1\}$ равновероятно. Если модель способна хорошо предсказать этот **случайный шум** — она слишком гибкая, склонна к переобучению.

**Сложность Рэдемахера** измеряет именно это: среднюю способность модели «попасть» в случайный шум.

- Маленькая сложность → модель не впитывает шум → хорошо обобщает.
- Большая сложность → модель впитывает шум → переобучается.

---

## 3. Формула эмпирической сложности Рэдемахера

**Определение.** Для класса функций $F$ на выборке $S = (x_1, \ldots, x_m)$:
$$\hat{\mathfrak{R}}_S(F) = \mathbb{E}_{\sigma}\!\left[\sup_{f \in F}\;\frac{1}{m}\sum_{i=1}^{m}\sigma_i\,f(x_i)\right],$$
где $\sigma_i$ — независимые случайные величины с $\mathbb{P}(\sigma_i = +1) = \mathbb{P}(\sigma_i = -1) = \tfrac{1}{2}$ (радемахеровские). Полное обозначение сложности — $\hat{\mathfrak{R}}_S(F)$; далее в вычислениях допускается сокращение $\hat{\mathfrak{R}}$, если выборка $S$ и класс $F$ понятны из контекста.

Пояснения к обозначениям в формуле:

| Символ | Что значит |
|---|---|
| $F$ | Класс функций («ящик» со всеми моделями одной формы) |
| $f \in F$ | Любая функция из класса — **не обученная**, а произвольная из ящика |
| $x_i$ | $i$-я точка **обучающей** выборки (не тестовой!) |
| $f(x_i)$ | Предсказание модели $f$ на $i$-й точке |
| $\sigma_i$ | Бросок монетки: $+1$ или $-1$ равновероятно |
| $\sigma_i \cdot f(x_i)$ | Согласие модели и монетки: $+1$ если согласны, $-1$ если нет |
| $\sum_i \sigma_i f(x_i)$ | Сумма согласий по всем точкам |
| $\frac{1}{m}$ | Нормировка, чтобы результат был в $[0, 1]$ |
| $\sup_{f \in F}$ | Перебираем все модели из ящика, выбираем лучшую по согласию с шумом |
| $\mathbb{E}_\sigma$ | Усреднение по всем $2^m$ возможным броскам монеток |

Формулу удобно читать последовательно:

1. Берём конкретную модель $f$ и конкретный набор монеток $\sigma$.
2. Считаем среднее согласие: $\frac{1}{m}\sum_i \sigma_i f(x_i)$ — число в диапазоне [-1, +1].
3. $\sup_{f \in F}$: выбираем из ящика модель, лучше всего согласованную с монетками.
4. $\mathbb{E}_\sigma$: усредняем результат по всем $2^m$ наборам монеток.

**Итог:** средняя по всем случайным разметкам способность лучшей модели в классе подстроиться под эту случайную разметку. Границы вроде $[0,1]$ требуют ограниченности значений $f(x)$; без такого ограничения сама формула не обязана лежать в этом интервале.

---

## 4. Что получаем по формуле

Число $\hat{\mathfrak{R}}_S(F) \in [0,1]$ — меру «гибкости» класса на конкретной выборке.

| Значение | Интерпретация |
|---|---|
| $\hat{\mathfrak{R}} \approx 1$ | Класс «впитывает» любой случайный шум → сильное переобучение |
| $\hat{\mathfrak{R}} \approx 0$ | Класс не может подстроиться под шум → хорошее обобщение |
| $\hat{\mathfrak{R}} = 0$ | Класс состоит из одной константы |

### Свойства

- **Зависит от выборки** $S$ (в отличие от VC).
- **Уменьшается с ростом $m$**: $\hat{\mathfrak{R}}_S \to 0$ при $m \to \infty$ для «хороших» классов.
- **Растёт с гибкостью класса**: чем больше функций в $F$, тем больше супремум.
- **Связана с обобщением напрямую**: чем меньше радиус, тем меньше зазор между обучающей и истинной ошибкой.
- **Выпуклая оболочка не меняет сложность:** $\hat{\mathfrak{R}}_S(\mathrm{conv}(F)) = \hat{\mathfrak{R}}_S(F)$.
- **Липшицева композиция:** если $g$ имеет константу Липшица $L$, то $\hat{\mathfrak{R}}_S(g \circ F) \leq L\hat{\mathfrak{R}}_S(F)$ (контракционное неравенство Маурера).

---

## 5. Граница обобщения

**Теорема (Bartlett–Mendelson, 2002).** Пусть $\sup_{f \in F}\|f\|_\infty \leq M$. С вероятностью $\geq 1 - \delta$ по выборке $S \sim \mathcal{D}^m$:
$$R(f) \;\leq\; \hat{R}_m(f) \;+\; 2\hat{\mathfrak{R}}_S(F) \;+\; 2M\sqrt{\frac{\ln(2/\delta)}{2m}}.$$

| Слагаемое | Что значит |
|---|---|
| $\hat{R}_m(f)$ | Ошибка на обучении (то, что обычно считаем) |
| $2\hat{\mathfrak{R}}_S(F)$ | Двойная сложность Рэдемахера (зазор за гибкость модели) |
| $2M\sqrt{\ln(2/\delta)/(2m)}$ | Статистическая часть зазора |
| $\delta$ | Вероятность того, что оценка НЕ выполняется (например, $\delta = 0{,}05$ → доверие 95%) |

В отличие от VC, эта оценка **зависит от конкретных данных** через $\hat{\mathfrak{R}}_S$.

### Сравнение с VC-границей

| | VC | Рэдемахер |
|---|---|---|
| Мера сложности | $h$ (целое, от данных не зависит) | $\hat{\mathfrak{R}}_S \in \mathbb{R}_+$ (зависит от выборки) |
| Применимость | бинарная классификация | произвольные ограниченные потери |
| Асимптотика зазора | $O(\sqrt{h\ln(m/h)/m})$ | $O(\hat{\mathfrak{R}}_S + 1/\sqrt{m})$ |
| Точность на практике | консервативная (в 2–5 раз больше CV) | обычно в 1,5–3 раза точнее VC |

## 6. Упрощённая оценка для линейных моделей

Для линейного класса $F = \{x \mapsto w^\top x : \|w\|_2 \leq B\}$ с $\|x_i\|_2 \leq R$ для всех $i$:
$$\hat{\mathfrak{R}}_S(F) \leq \frac{BR}{\sqrt{m}}.$$

**Граница обобщения:**
$$R(f) \;\leq\; \hat{R}_m(f) \;+\; \frac{2BR}{\sqrt{m}} \;+\; 2M\sqrt{\frac{\ln(2/\delta)}{2m}}.$$

### Доказательство

Точная формула для линейного класса:
$$\hat{\mathfrak{R}}_S(F) = \frac{B}{m}\,\mathbb{E}_\sigma\!\left\|\sum_{i=1}^{m}\sigma_i x_i\right\|_2.$$

Применяя неравенство Йенсена и $\mathbb{E}[\sigma_i\sigma_j] = \delta_{ij}$:
$$\mathbb{E}_\sigma\!\left\|\sum_i \sigma_i x_i\right\|_2 \leq \sqrt{\mathbb{E}_\sigma\!\left\|\sum_i \sigma_i x_i\right\|_2^2} = \sqrt{\sum_i \|x_i\|_2^2} \leq \sqrt{mR^2} = R\sqrt{m}.$$

Супремум по $w$ с $\|w\|_2 \leq B$ даёт множитель $B$. Итого: $BR/\sqrt{m}$. $\square$

### Что такое $\|w\|$ и $\|x_i\|$

Для линейного классификатора $f(x) = w^\top x$ веса — это **вектор** $w = (w_1, \ldots, w_d)$, по одному весу на признак. Используется евклидова норма:
$$\|w\|_2 = \sqrt{w_1^2 + w_2^2 + \ldots + w_d^2},\qquad \|x_i\|_2 = \sqrt{x_{i,1}^2 + \ldots + x_{i,d}^2}.$$

**Условие $\|w\|_2 \leq B$ НЕ означает «каждый вес $\leq B$».** Это ограничение на общую длину вектора весов. Например, при $B = 1$:
- $w = (1, 0, 0, 0)$ → $\|w\| = 1$ ✓
- $w = (0{,}5, 0{,}5, 0{,}5, 0{,}5)$ → $\|w\| = 1$ ✓
- $w = (1, 1, 1, 1)$ → $\|w\| = 2$ ✗

Условие $\|x_i\|_2 \leq R$ — аналогично, ограничение на общую длину вектора признаков $i$-го объекта (не на каждый признак).

**Откуда берутся $B$ и $R$ на практике:**
- $B$ контролируется L2-регуляризацией: штраф $\lambda\|w\|^2$ в функции потерь заставляет модель распределять веса.
- $R$ контролируется стандартизацией признаков (z-score): если признаки центрированы и нормированы, $\|x_i\| \approx \sqrt{d}$.

### Три рычага уменьшения сложности

Из $\hat{\mathfrak{R}} = BR/\sqrt{m}$:

1. **Усиливаешь регуляризацию** → $B \downarrow$ → $\hat{\mathfrak{R}} \downarrow$.
2. **Нормируешь признаки** → $R \downarrow$ → $\hat{\mathfrak{R}} \downarrow$.
3. **Собираешь больше данных** → $m \uparrow$ → $\hat{\mathfrak{R}} \downarrow$ как $1/\sqrt{m}$.

## 7. Задания

### Задание 1. Базовый кредитный скоринг

**Сценарий.** Банк обучает линейную модель выдавать/отказывать в кредите. После L2-регуляризации $\|w\|_2 \leq 1$ ($B = 1$). Признаки нормированы: $\|x_i\|_2 \leq 3$ ($R = 3$). Исторических данных $m = 1000$ заявок. На обучении $\hat{R}_m = 0{,}05$.

**Вопрос.** С какой гарантией и насколько можно утверждать, что истинная ошибка не превысит порог? $\delta = 0{,}05$.

**Решение.**
$$\hat{\mathfrak{R}} \leq \frac{1 \cdot 3}{\sqrt{1000}} \approx 0{,}095.$$
$$R \leq 0{,}05 + 2 \cdot 0{,}095 + 2\sqrt{\frac{\ln 40}{2000}} \approx 0{,}05 + 0{,}19 + 0{,}122 \approx 0{,}362.$$

**Ответ:** с вероятностью 95% истинная ошибка не превысит $\approx 36\%$, хотя на обучении 5%.

---

### Задание 2. Эффект размера выборки

**Сценарий.** Маленький банк собрал $m = 100$ заявок, крупный — $m = 10000$. У обоих $B = 1$, $R = 1$.

**Вопрос.** Во сколько раз уменьшится сложность Рэдемахера при росте выборки в 100 раз?

**Решение.**
- Малый банк: $\hat{\mathfrak{R}} = 1/\sqrt{100} = 0{,}1$.
- Крупный банк: $\hat{\mathfrak{R}} = 1/\sqrt{10000} = 0{,}01$.

**Ответ:** в 10 раз. Закон $1/\sqrt{m}$: рост $m$ в $k$ раз уменьшает $\hat{\mathfrak{R}}$ в $\sqrt{k}$ раз.

---

### Задание 3. Эффект усиления регуляризации

**Сценарий.** Банк усилил L2-регуляризацию: $\|w\|$ упал с $B = 2$ до $B = 0{,}5$. Данные те же: $R = 1$, $m = 500$.

**Вопрос.** Как изменится сложность Рэдемахера?

**Решение.**
- До: $\hat{\mathfrak{R}} = 2/\sqrt{500} \approx 0{,}089$.
- После: $\hat{\mathfrak{R}} = 0{,}5/\sqrt{500} \approx 0{,}022$.

**Ответ:** уменьшилась в 4 раза (пропорционально $B$). Линейная зависимость — следствие свойства нормировки $\hat{\mathfrak{R}}_S(cF) = |c|\,\hat{\mathfrak{R}}_S(F)$.

---

### Задание 4. Эффект нормализации признаков

**Сценарий.** Признаки: доход (до 200 тыс. руб.), стаж (до 40 лет), возраст (до 80). Без нормировки $R \approx \sqrt{200^2 + 40^2 + 80^2} \approx 220$. После стандартизации $R = 3$. $B = 1$, $m = 1000$.

**Вопрос.** Какой эффект даст стандартизация?

**Решение.**
- Без нормировки: $\hat{\mathfrak{R}} = 220/\sqrt{1000} \approx 6{,}96$ — оценка бессмысленна (больше 1).
- После: $\hat{\mathfrak{R}} = 3/\sqrt{1000} \approx 0{,}095$.

**Ответ:** сложность уменьшилась в $\approx 73$ раза. Нормировка признаков — обязательный шаг для линейных моделей.

---

### Задание 5. Сравнение VC и Рэдемахера

**Сценарий.** Линейный классификатор в $\mathbb{R}^{10}$ ($h = 11$), $m = 500$, $\hat{R}_m = 0{,}05$, $\delta = 0{,}05$, $B = R = 1$.

**Вопрос.** Какая граница точнее?

**Решение.**
**VC:**

$$R \leq 0{,}05 + \sqrt{\frac{11\ln(2e \cdot 500/11) + \ln 80}{1000}} \approx 0{,}306.$$

**Рэдемахер:**

$$R \leq 0{,}05 + \frac{2}{\sqrt{500}} + \sqrt{\frac{\ln 40}{1000}} \approx 0{,}05 + 0{,}089 + 0{,}061 \approx 0{,}200.$$

**Ответ:** Рэдемахер в $1{,}53$ раза точнее. Он «видит» конкретные $B$ и $R$, а VC — только $h$.

---

### Задание 6. Прогноз направления цены акций

**Сценарий.** Хедж-фонд предсказывает знак доходности акции: $+1$ — вырастет, $-1$ — упадёт. Признаки — 20 доходностей за прошлые дни в $[-1, 1]$, $\|x_i\|_2 \leq \sqrt{20}$. $B = 1$, $m = 500$.

**Вопрос.** Достаточно ли 500 дней для надёжного прогноза?

**Решение.**
$$\hat{\mathfrak{R}} = \frac{\sqrt{20}}{\sqrt{500}} = 0{,}2.$$
$$R \leq \hat{R}_m + 2 \cdot 0{,}2 + \sqrt{\frac{\ln 40}{1000}} \approx \hat{R}_m + 0{,}461.$$

**Ответ:** даже при $\hat{R}_m = 0{,}4$ (60% верных прогнозов) истинная ошибка может быть до $0{,}86$. Финансовые данные очень шумные — нужно больше данных или признаки с меньшим $R$.

---

### Задание 7. Проклятие размерности

**Сценарий.** Банк расширил число признаков с $d = 5$ до $d = 50$. Каждый признак в $[-1, 1]$, $R = \sqrt{d}$. $B = 1$, $m = 1000$.

**Вопрос.** Во сколько раз вырастет сложность?

**Решение.**
- $d = 5$: $\hat{\mathfrak{R}} = \sqrt{5}/\sqrt{1000} \approx 0{,}071$.
- $d = 50$: $\hat{\mathfrak{R}} = \sqrt{50}/\sqrt{1000} \approx 0{,}224$.

**Ответ:** в $\sqrt{10} \approx 3{,}16$ раза. Чтобы компенсировать, нужно в 10 раз больше данных ($m = 10000$).

---

### Задание 8. Требуемый размер выборки для ипотеки

**Сценарий.** Банк запускает модель ипотечного скоринга с гарантией $\varepsilon = 0{,}05$ (истинная ошибка отличается от обучающей не более чем на 5%). Признаков $d = 20$, $R = \sqrt{20}$, $B = 1$, $\delta = 0{,}05$.

**Вопрос.** Сколько исторических ипотечных заявок нужно собрать?

**Решение.** Требуем $2\hat{\mathfrak{R}} \leq \varepsilon$:
$$\frac{2BR}{\sqrt{m}} \leq \varepsilon \;\Rightarrow\; m \geq \left(\frac{2BR}{\varepsilon}\right)^2 = \left(\frac{2\sqrt{20}}{0{,}05}\right)^2 = (40\sqrt{20})^2 = 32000.$$

**Ответ:** $\approx 32000$ заявок. VC для $h = 21$ дал бы порядка $50000$ — Рэдемахер реалистичнее.

---

### Задание 9. Trade-off: данные vs регуляризация

**Сценарий.**
- **Банк А (стартап):** $m = 100$ кредитов, очень сильная регуляризация $B = 0{,}1$, $R = 1$.
- **Банк Б (крупный):** $m = 10000$ кредитов, слабая регуляризация $B = 1$, $R = 1$.

**Вопрос.** У какого банка лучше гарантия обобщения?

**Решение.**
- Банк А: $\hat{\mathfrak{R}} = 0{,}1/\sqrt{100} = 0{,}01$.
- Банк Б: $\hat{\mathfrak{R}} = 1/\sqrt{10000} = 0{,}01$.

Сложность Рэдемахера **одинаковая**! Но статистическая часть зазора разная:
- Банк А: $\sqrt{\ln 40/200} \approx 0{,}122$.
- Банк Б: $\sqrt{\ln 40/20000} \approx 0{,}012$.

При $\hat{R}_m = 0{,}10$ у обоих:
- Банк А: $R \leq 0{,}10 + 0{,}02 + 0{,}122 = 0{,}242$.
- Банк Б: $R \leq 0{,}10 + 0{,}02 + 0{,}012 = 0{,}132$.

**Ответ:** сложность Рэдемахера одинаковая — стартап компенсировал нехватку данных жёсткой регуляризацией. Но статистическая часть зазора у стартапа в 10 раз больше, поэтому крупный банк выигрывает в итоге (13% vs 24%).

### Задание 10. Линейная модель vs нейросеть

**Сценарий.** Для задачи кредитного скоринга ($m = 1000$, $R = 1$) рассматривают две модели:
- **Линейная** с $B = 1$: $\hat{\mathfrak{R}}_{\text{лин}} = 1/\sqrt{1000} \approx 0{,}032$.
- **Нейросеть** с $W \sim 10^4$ параметрами: для полносвязной сети $\hat{\mathfrak{R}}_{\text{NN}} \sim O(\sqrt{W/m})$, грубо $\hat{\mathfrak{R}}_{\text{NN}} \approx 0{,}32$.

**Вопрос.** Какая модель надёжнее на $m = 1000$?

**Решение.**

| Модель | $\hat{\mathfrak{R}}$ | Зазор $2\hat{\mathfrak{R}}$ |
|---|---|---|
| Линейная ($B = 1$) | $0{,}032$ | $0{,}064$ |
| Нейросеть ($\sim 10^4$ весов) | $\sim 0{,}32$ | $\sim 0{,}64$ |

**Ответ:** нейросеть в 10 раз «гибче» линейной модели — её радиус в 10 раз больше. На $m = 1000$ нейросеть почти наверняка переобучится. Либо нужно $10\times$ больше данных, либо сильная регуляризация (dropout, weight decay).

Этим объясняется, почему для табличных данных в банковском скоринге линейные модели часто выигрывают у нейросетей.

## 9. Выводы

1. **$x_i$ в формуле — точки обучающей выборки** (не тестовой!).
2. **$f$ — любая модель из класса $F$**, не обученная. $\sup$ выбирает лучшую по согласию с шумом.
3. **$\hat{\mathfrak{R}}_S \in [0,1]$** — действительное число, мера гибкости класса на конкретной выборке.
4. **$\|w\|_2 \leq B$ ограничивает общую норму весов** (через L2-регуляризацию), не каждый вес.
5. **$\|x_i\|_2 \leq R$ ограничивает общую норму признаков** каждого объекта (через стандартизацию).
6. **Для линейных моделей:** $\hat{\mathfrak{R}} \leq BR/\sqrt{m}$ — простая рабочая формула.
7. **Три рычага уменьшения сложности:** регуляризация ($B$), нормировка ($R$), данные ($m$).
8. **Нормируй признаки, регуляризуй веса, набирай данные** — три кита хорошего обобщения.

## 11. Словарь терминов

| Термин | Краткое определение | Роль в семинаре |
|---|---|---|
| Обобщение | Способность модели сохранять качество на новых данных. | Главная проблема, которую оценивает граница обобщения. |
| Эмпирический риск $\hat{R}_m(f)$ | Средняя ошибка функции $f$ на обучающей выборке из $m$ объектов. | Наблюдаемая часть границы. |
| Истинный риск $R(f)$ | Ожидаемая ошибка на случайном новом объекте из распределения данных. | Искомая величина. |
| Класс функций $F$ | Множество допустимых моделей одной формы или с общим ограничением. | Объект, чью гибкость измеряет сложность. |
| Сложность (радиус) Рэдемахера $\hat{\mathfrak{R}}_S(F)$ | Средняя способность лучшей функции из $F$ согласоваться со случайными знаками на конкретной выборке $S$. | Данные-зависимая мера сложности. |
| Радемахеровские знаки $\sigma_i$ | Независимые случайные величины, равные $+1$ или $-1$ с вероятностью $1/2$. | Создают случайную разметку для проверки гибкости класса. |
| Супремум $\sup$ | Точная верхняя грань множества значений; здесь — выбор лучшей функции из $F$. | Показывает, что класс может адаптироваться к шуму. |
| VC-размерность $h$ | Максимальный размер множества, которое класс может разбить всеми бинарными разметками. | Альтернативная, обычно более грубая мера сложности. |
| Норма $\|w\|_2$ | Евклидова длина вектора весов $w$. | Ограничение $\|w\|_2\le B$ контролирует сложность линейного класса. |
| Норма признаков $\|x_i\|_2$ | Евклидова длина вектора признаков объекта $x_i$. | Ограничение $\|x_i\|_2\le R$ отражает масштаб данных. |
| L2-регуляризация | Штраф, пропорциональный $\|w\|_2^2$, в функции обучения. | Уменьшает допустимый масштаб весов и параметр $B$. |
| Стандартизация | Приведение признаков к сопоставимому масштабу, например z-score. | Помогает уменьшить и контролировать $R$. |
| Зазор | Разность между гарантированной верхней оценкой истинного риска и эмпирическим риском; зависит от сложности, $m$ и $\delta$. | Показывает, насколько гарантированно истинный риск может быть выше наблюдаемого. |
| $\delta$ | Вероятность нарушения вероятностной гарантии. | При $\delta=0{,}05$ доверие составляет 95%. |
| Липшицева композиция | Композиция с функцией, изменения которой ограничены константой Липшица $L$. | Используется для переноса оценки сложности через нелинейность. |
| Переобучение | Ситуация, когда модель хорошо подстроилась под обучение, но плохо обобщает. | Интерпретируется как чрезмерная способность впитывать шум. |

> **Замечание.** Обозначения $R(f)$, $\hat{R}_m(f)$ и $\hat{\mathfrak{R}}_S(F)$ различны: соответственно истинный риск, эмпирический риск и эмпирическая сложность класса.
